## 📋 Architectural Characteristics & Intended Limitations

1. **Zero-Backend Architecture:** The book is intentionally built as a purely static website (HTML5, CSS3, ES6 JavaScript) to guarantee zero hosting costs, infinite scale on GitHub Pages or S3/CloudFront, and complete independence from backend servers or databases.
2. **Device-Local Progress Storage:** In alignment with the static, zero-cookie design, reading progress (completion toggles and revision bookmarks) is persisted in the user's browser `localStorage`. Progress does not synchronize cross-device without an authenticated backend.
3. **Curriculum Metadata Search:** Global search (`Ctrl+K` or `/`) indexes curriculum chapter titles, summaries, tags, and topics in client memory (~50KB payload), delivering instantaneous, sub-millisecond keyword filtering without requiring heavy third-party search libraries (such as Lunr or Elastic).
4. **Lightweight Tokenizer:** Syntax highlighting (`prism.js`) utilizes a zero-dependency, regex-based client tokenizer rather than full AST parsers, optimizing for zero-lag page rendering across low-power mobile devices.
